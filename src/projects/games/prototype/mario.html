mario maker

11/2024 - 12/2024

I created an small mario maker like.

images

outils utilisées

C++ - SFML

fonctionnalités

  • création de niveaux
  • mode jeu sur la map créer
  • modes multiples
  • sauvegarde/chargement de la map
  • Tilemap
  • gestion des collisions

création de niveaux

Le léger éditeur de niveaux permet de placer des éléments de maps ou des ennemies.

mode jeu sur la map créer

Le mode jeu permet de jouer sur la map créer dans l'éditeur.

modes multiple

Gestion de plusieurs systèmes de boucle en fonction du mode (éditeur / jeu).

sauvegarde/chargement de la map

La map crée dans l'éditeur est sauvegardée dans un fichier texte et est relancée au lancement des différents modes.

Tilemap

La map est générée à l'aide d'un système de TileMap, où chaque case d'une matrice 2D correspond à un type de bloc affiché à l'écran

gestion des collisions

Les collisions sont gérées manuellement en comparant les bords de la box de collision du joueur avec ceux des blocs solides.
