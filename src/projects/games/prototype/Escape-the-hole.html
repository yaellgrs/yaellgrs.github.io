Escape-The-Hole

10/2025 - 11/2025

Ceci est un prototype de jeux vidéo créer pour répondre a un test d'une offre d'emploie.

Les consignes étaient de répliquer le jeu "All in Hole" mais en rajoutant des modifications, le jeu a été créé en 10 jours.

images

outils utilisées

c# - Unity3D

  • Git
  • AI-navMesh

Le projet a été versionné sur git pour permettre au recruteur de voir l'évolution du projet ainsi que son organisation.

L'ennemie est controllé par un système un agent ia.

fonctionnalités

  • niveaux
  • speedrun
  • leveling

Le jeu possède un système de niveaux avec une difficulté progressive

Chaque partie est chronométré et chaque niveau a son record de complétion

ssssssssssssssssssssss

Le joueur doit manger des angrais sur la map pour monter en niveau, représenté par différents fruit de taille croissante.
