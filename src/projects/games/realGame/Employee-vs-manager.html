Manager-vs-employee

09/2025 - 12/2025

02/2026 ( normalement ) - futur

Employer-vs-Manager est un jeu créer a 4, dont 3 développeur et 1 modélisatrice. Le but étant de créer un jeu multijoueur agréable et amusant qui sera poster sur steam.

images

outils utilisées

c# - Unity2D

  • UIToolkit
  • NGO
  • AI-NavMesh
  • Git

Toutes les interfaces ont été fait avec UIToolkit et sont liés par un script.

Le multijoueur a été fait avec network for gameObject

Les calcules de déplacement de bots ont été basé sur les outils proprosé avec NavMesh agent.

Le travail en équipe a pu être possible grace a git, où chaque personne travaillais sur branche.

fonctionnalités

  • Multijoueur
  • Missions

Pour pouvoir stocker des nombres sont sans limite de taille tout en gardant de bonnes performances j'ai codé la class BigNumber qui se base sur la notation scientifique.

Au cours de la partie différentes missions assez variés, sous forme de tache ou sabotages sont proposés
